## Overview

Describe the high-level installation flow: creating an account, connecting a source control provider, and kicking off an initial index.

## Steps

<Steps>
  <Step title="Connect your source control provider">
    Link Lightbase to GitHub, GitLab, or Bitbucket. See [Source control providers](/getting-started/source-control).
  </Step>
  <Step title="Choose repositories to index">
    Select which repositories Lightbase should analyze. See [Selecting repositories](/getting-started/repositories).
  </Step>
  <Step title="Run the initial index">
    Start the first analysis. See [Indexing your code](/getting-started/indexing).
  </Step>
</Steps>
