---
title: "Supported languages"
description: "The languages Indexer analyzes."
---

Indexer analyzes the following languages:

- C
- C#
- Go
- Java
- JavaScript
- Kotlin
- PHP
- Python
- Rust
- SQL
- Shell
- TypeScript

Everything [Indexer](/core-concepts/indexing-process) does applies to each of them: entrypoints, the code flows that run from them, and the interactions those flows reach. A repository that mixes several languages is analyzed in all of them, and each file is read by the analyzer for its own language.

Files written in a language that is not listed are not analyzed and do not appear in the model. Their presence in a repository does not affect the analysis of the rest.
