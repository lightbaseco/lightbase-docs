Lightbase detects how your code interacts with systems beyond itself:

## Database access

Detects database access and reconstructs schemas.

## Cross-service calls

Detects calls between your services.

## Message queues

Detects interactions with message queues.

## Counterparties

Detects external entities your code interacts with. See [Counterparties](/data-curation/counterparties).

## File access

Detects file system access.
