Lightbase analyzes entrypoints per framework to reconstruct the code flows of your entire application:

- **HTTP entrypoints** — analyzed per web framework.
- **Queue entrypoints** — analyzed per queue library.
- **CLI entrypoints** — command-line entrypoints.

Together, these entrypoints give Lightbase the code flows across the whole application.

## View detection

Lightbase detects the views of frontend applications, the actions they allow, and the endpoints they call.
