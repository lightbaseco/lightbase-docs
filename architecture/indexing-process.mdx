Unlike static analysis systems, Lightbase traces business flows end-to-end — even when a single flow spans multiple services through network calls, message queues, and other boundaries. This is what lets Lightbase link external service calls and database access back to the concrete business flows that drive them.

## Initial vs. incremental indexing

- **Initial indexing** — the first full analysis of your code.
- **Incremental (delta) indexing** — updates as your code changes.
  - Daily reindexing runs by default.
  - Real-time indexing is available through your account manager.
