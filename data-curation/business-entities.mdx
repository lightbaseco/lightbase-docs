---
title: "Business entities"
description: "Group tables that are part of the same business concept."
---

A [business entity](/core-concepts/business-entities) defines a single business concept that is distributed through multiple tables. `Users` is an entity: the users table plus every normalized table hanging off it — profiles, credentials, addresses, preferences, consents. Your domain has one word for all of that. The entity holds all the tables behind it.

An entity can span databases and services. When several services write the same concept, one entity covers every table involved, so a question about `Users` returns all of them.

## Where the first entities come from

Lightbase generates a first set of entities from your code and your curated schema. Treat that set as a starting point. Entity vocabulary is company-specific: one organization's *customer* is another's *account*, and a third calls it a *party* because that is the word its regulator uses.
